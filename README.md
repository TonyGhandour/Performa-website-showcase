# PERFORMA

**Built to Perform.**

Performa is a modern lifestyle and hydration brand focused on combining performance, functionality, and clean design.

This repository contains the official Performa website, built as a custom modern web application with a strong focus on responsive design, fast performance, and a premium brand experience.

🌐 Live website: https://performalb.com

---

## About Performa

Performa was created around a simple idea:

> More than a bottle — a lifestyle for those who move with intention.

The website is designed to showcase Performa products through a clean, high-performance user experience across desktop and mobile devices.

The first product collection includes reusable performance water bottles in multiple sizes and colors.

## Tech Stack

The website is built using a modern TypeScript-based frontend stack.

- **React**
- **TypeScript**
- **TanStack Start / TanStack Router**
- **Vite**
- **Tailwind CSS**
- **Cloudflare**
- **Git / GitHub**

The project is designed to remain lightweight, scalable, and easy to extend as Performa grows.

---

## Main Features

### Responsive Design

The website is fully responsive and optimized for:

- Desktop
- Tablet
- Mobile

Desktop and mobile layouts are handled independently where needed to maintain the intended visual experience.

### Cinematic Hero Section

The homepage includes a custom visual hero section designed around the Performa identity.

It includes:

- Responsive desktop and mobile hero backgrounds
- Brand messaging
- Product navigation
- Interactive call-to-action buttons
